# Статус RobotsHub

Статус функций на 29 сентября 2026 года. Публичная версия: [robotshub.ru](https://robotshub.ru/). Для воспроизводимой проверки сборки см. [маршрут проверяющего](REVIEWER_GUIDE.md).

## Работает

- Карта: 223 исходные записи внедрений, 12 направлений и пересекающихся тематических срезов; досье и источники данных.
- Каталог: 224 исходные записи решений, фильтры, карточки с атрибутированными изображениями, стоимость и сравнение. На странице после фильтрации отображается меньше карточек; не каждое решение подходит для расчёта конкретного объекта.
- Типовые объекты склада, аэропорта и медучреждения, а также собственный бриф. XLSX-анкеты этих типов можно скачать и загрузить с проверкой полей и явным подтверждением замены проекта.
- Предварительная экономика для поддерживаемых операций: сценарии финансирования, TCO, ROI, what-if, вердикт и моделирование риска окупаемости на странице расчёта.
- Симуляция выбранного решения по параметрам объекта: маршруты роботов, этажи, лифт, зарядка и стационарные установки. Отдельная песочница показывает готовые сцены и не влияет на проект.
- Отчёт с экспортом PDF/CSV. Проект сохраняется локально в браузере, без аккаунта.
- CI: проверка типов, тесты карты, расчёта и пользовательского маршрута, сборка Docker, HTTP smoke и браузерный тест собранной версии. Проверка XLSX-анкет запускается отдельно командой из [VALIDATION.md](VALIDATION.md); добавление её в GitHub Actions подготовлено локально.

## Ограничения

- ТЭО и симуляция — модели для предварительной оценки, не гарантия эффективности и не подтверждение применимости каждой модели робота к каждому объекту.
- Данные проекта остаются в localStorage конкретного браузера: синхронизации между устройствами и серверной истории нет.
- XLSX-анкеты содержат параметры объекта, но не планы этажей, трассы движения или финансовые документы. Автотесты покрывают сохранение в настольных Excel и LibreOffice и простые inline-строки openpyxl; совместимость со всеми версиями и редакторами не заявляется.
- Качественные и количественные характеристики карточек следует сверять по указанным первичным источникам; отсутствие подтверждённого значения не заменяется предположением.

## Следующий этап

- Аккаунты и перенос сохранённых проектов между устройствами — только после определения требований к доступу и хранению данных.
- Добавить распределения риска окупаемости и состава TCO в итоговый отчёт; сейчас риск доступен на странице расчёта.
- Расширить проверку XLSX на другие версии офисных редакторов и документы с нестандартной структурой.
- Включить `test:questionnaire` в GitHub Actions после получения доступа к обновлению файла workflow.
