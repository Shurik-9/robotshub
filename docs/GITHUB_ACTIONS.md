# Обновление GitHub Actions

В комплекте подготовлена расширенная проверка `.github/workflows/verify.yml`: XLSX, входной сценарий/DOCX, связи каталога, SEO новостей и HTTP-проверки новых страниц Docker.

При синхронизации 20 октября 2026 подключение GitHub отклонило изменение пути `.github/workflows/verify.yml` (`404` при создании дерева с этим файлом). Остальной исходный код можно передать. Существующий удалённый workflow оставлен без изменений, чтобы не создавать ложного впечатления обновлённого CI.

Готовая новая конфигурация лежит рядом: [github-actions-verify.yml](github-actions-verify.yml). Владелец репозитория может открыть `.github/workflows/verify.yml` в GitHub, заменить его содержимым этого файла и сохранить коммит. После этого проверьте запуск во вкладке Actions. Наличие конфигурации или локально успешные тесты не означают успешный запуск CI на GitHub.
