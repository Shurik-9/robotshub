# Безопасность

Не публикуйте в Issues пароли, токены, данные заказчика, содержимое localStorage или конфиденциальные документы. Об уязвимостях сообщайте владельцу репозитория приватно, например через GitHub Security Advisory, если эта возможность включена.

Для запуска веб-приложения секреты не требуются; `.env.example` содержит только необязательный номер порта. `DATABASE_URL` понадобится лишь для отдельного запуска API-каркаса, который не входит в Docker Compose.
