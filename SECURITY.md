# Безопасность

Не публикуйте в Issues пароли, токены, данные заказчика, содержимое localStorage или конфиденциальные документы. Уязвимости передавайте владельцу закрытого репозитория через приватное сообщение или GitHub Security Advisory, если эта возможность включена.

Для веб-демонстрации не требуются секреты; `.env.example` содержит только необязательный номер порта. `DATABASE_URL` понадобится **только** если в будущем отдельно запускается API-каркас. Не копируйте секреты Replit в GitHub, Dockerfile или `.env.example`. Перед передачей проверяйте как рабочие файлы, так и историю публикуемого Git-репозитория.
